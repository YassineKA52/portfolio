Courag
September 2026 shipped

A retrieval-augmented generation (RAG) system that answers questions on course PDFs and cites the exact page each answer came from. Combines pgvector cosine similarity with PostgreSQL full-text search via reciprocal rank fusion, runs multilingual text embeddings locally through ONNX Runtime (cutting the deployed image from ~3 GB to 250 MB), and streams grounded answers from the Anthropic Claude API over server-sent events.
